# OpenList

Unofficial Home Assistant add-on packaging for [OpenList](https://github.com/OpenListTeam/OpenList). The current experimental release packages OpenList `v4.2.4` for `amd64`.

See [the add-on documentation](DOCS.md) for installation, storage, networking, and backup guidance.
